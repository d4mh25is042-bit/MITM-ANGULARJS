College Event Registration System

Project Description

The College Event Registration System is a web-based application developed using AngularJS. It helps students view upcoming college events and register for their favourite events easily.

The system simplifies the event registration process and helps college organizers manage event participation.

Objectives

- To provide information about upcoming college events.
- To make student event registration easy.
- To reduce manual registration work.
- To provide registration confirmation.

Features

1. Home page
2. Upcoming events display
3. Event details
4. Student registration form
5. Registration confirmation

Technologies Used

- HTML
- CSS
- JavaScript
- AngularJS

How to Run the Project

1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open index.html.
5. Right-click and select Open with Live Server.
